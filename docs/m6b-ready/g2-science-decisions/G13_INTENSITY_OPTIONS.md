# G13 时长增长与吞吐代理

PAPER p26只给20%阈值，p43的5%–85%未唯一说明是限频比、计算变慢、迭代变慢还是吞吐下降。推荐A=(d-b)/b直接迭代时长主指标，B=(d-b)/d和实测吞吐单列；选择根据测量语义，不能依据fixture结果挑分母。b,d为当前filtered窗口左/右均值，单位ms；d右侧含cp。严格>0.2，等号不通过，不四舍五入/加容差。

有效正时长 B=A/(1+A)。A>0.2要求d>1.2b；B>0.2要求d>1.25b。W固定且时间边界可比时B对应W/d对W/b的损失；不等于实测work/walltime，也不等于mean(W/t_i)。频率百分比不能直接映射两者。

| b→d ms | A | A>0.2 | B | B>0.2 |
|---|---|---|---|---|
| 100→119 | 19/100 | false | 19/119 | false |
| 100→120 | 1/5 | false | 1/6 | false |
| 100→121 | 21/100 | true | 21/121 | false |
| 100→125 | 1/4 | true | 1/5 | false |
| 100→126 | 13/50 | true | 13/63 | true |

表中精确有理数只核验边界；实际历史前缀按原binary64均值和严格比较，绝不先按标签/显示位数判决。100→120的A等于0.2不通过；100→125的B等于0.2不通过。

全部七场景见SCENARIO_COMPARISON.json，包含两批、所有首次口径和分歧前缀；growth20 A在23等前缀通过，是实际浮点均值变化，growth21 A22起通过而B没有。recovery30–32也有A/B分歧。source sensitivity保留所有候选槽/均值/count/概率/过滤，不能只展示好看的点。

缺失/零负时长/None/bool/string/NaN/Inf与零分母明确insufficient/null，不填零作健康证据；恢复不足和有效不越线分开。参数/标签/样本/阈值不改。
