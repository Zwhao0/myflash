# 证据入口

RESULT.md/validation.json 报告实际 CPU 结果及整体 BLOCKED；APPROVAL.md/SOURCES.md/任务文件给范围和来源；runtime/ 给固定身份、原 API/full-short 原件脱敏和 RNG；data/ 是原比较器两个完整矩阵的全部 JSON 原字节；batches/ 是完整 expected/worker/artifact/native-command 回执；commands/ 和 logs/ 给每项原 argv/退出/输出（路径及进程别名）；raw-public-correspondence.json/raw-index.json 绑定私有原件 SHA。

formal-files.json/source-files.json/preservation.json/postflight.json/postflight-private.json/formal-full-audit.json 给实际保护范围；FULL_MANIFEST_GAP.md/full-manifest-gap.json 明确915缓存前测缺失；continuation/ 和 INVOCATION_REPAIR.md 留第一次失败与补测、原数据不可变证据；failure-index.json、FORMAT_FAILURE.md、local-checks.json 保留所有已知失败。EXPORTER.py/FINISHER.py/NATIVE_GATE_AUDIT.py/PRIVACY_LITERAL_CHECK.py 给本轮新证据代码。

相邻 g1-s2-c-preflight/ 七文件是此前未上传的原只读预检，原状态不改。本轮无 third-party wheel/full source；许可证与历史隐私仍 DEFERRED/OPEN。发布精确 head/tree/真实 CI 见 PR 描述与私有 publication 回执；隐私 CI 不验证科学/GPU 或弥补完整前测缺口。
