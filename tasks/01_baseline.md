# M1：无FLASH的通信与训练底座

只有全新仓库的 M0 已审核通过并明确资源预算后执行。阅读 AGENTS/SPEC/GAPS/PLAN/STATUS 以及 M0 的 ARCHITECTURE.md、SOURCE_MAP.md、ENVIRONMENT_PLAN.md。

本轮目的不是做检测器，而是确认故障定位系统将依赖的训练与通信本身可运行。禁止设置LD_PRELOAD注入FLASH/Greyhound；禁止故障注入；不要升级驱动、CUDA、NCCL或整个训练栈。

先提交拟修改文件、环境探测项、测试命令、使用GPU UUID、最长时长、退出/清理方式。记录缺失依赖；需要安装时停止申请批准。在新项目中新建**最小可复现基线入口**，可使用公开、固定版本的 nccl-tests 或官方 PyTorch 分布式测试工具；不复制过去失败实现的训练脚本。训练框架需按论文目标选择并固定版本，不为通过测试临时更换。

把测试拆为可单独执行的子任务：
- M1a：只读环境与版本清单，确认两台实际可用卡数、实际加载NCCL、网卡/链路与进程组后端。
- M1b：单机2rank AllReduce正确性与限定时长循环，使用有已知结果的张量并检查输出。
- M1c：两机各1rank运行同一测试，确认rank/host/GPU映射与实际通信路径。
- M1d：经批准后扩展至全卡；小型DDP训练固定步数，记录loss、迭代时间、数值检查、所有进程退出码。
- M1e：确认目标Megatron/MoE启动前置条件，能运行则进行已获准的最小冒烟；不能运行就记录具体缺失，不暗中换模型并声称原配置通过。
